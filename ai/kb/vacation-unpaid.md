# Отпуск без сохранения заработной платы

## Что это
Отпуск без сохранения заработной платы — это дни отдыха, за которые зарплата не начисляется. Он предоставляется по письменному заявлению работника.

## Обязательные случаи
По заявлению работника отпуск без сохранения заработной платы продолжительностью до пяти календарных дней предоставляется при регистрации брака, рождении ребёнка, смерти близких родственников.

## Другие случаи
В остальных случаях отпуск без сохранения заработной платы предоставляется по соглашению между работником и работодателем. Продолжительность согласуется с руководителем.

## Как оформить
Политика компании: напишите заявление через HR-менеджера и согласуйте даты с руководителем. Онлайн-форма для этого вида отпуска в JanaMen пока не предусмотрена.
Дни отпуска без сохранения заработной платы не уменьшают остаток ежегодного оплачиваемого отпуска.
